# Bohr-level gap analysis for Tamesis M_c v1

## Current experimental frontier

The strongest observed center-of-mass matter-wave records now sit far below the
Tamesis critical mass:

- molecular interference beyond 25 kDa;
- sodium nanoparticle interference above 170 kDa;
- roadmap/proposal targets around 1e8 to 1e11 amu.
- a 2026 nanodiamond/chip proposal targets 1e-19 kg to 1e-15 kg, which crosses
  the Tamesis threshold, but it is not an observed result.

Tamesis v1 predicts:

```text
M_c = 5.292674126388712e-16 kg
M_c = 3.1873228596937555e11 amu
```

The best observed center-of-mass interference point in the current table is
the 170 kDa sodium nanoparticle result:

```text
M / M_c = 5.33e-7
```

So the observed frontier is still about 1.9 million times below the threshold.

## Why this is not Bohr-level yet

Bohr-level status needs a clean anomaly or regularity that existing theory does
not already absorb. The current data only say that low-mass systems remain
coherent, which standard quantum theory, CSL, GRW, DP and Tamesis all expect.

The present table is therefore not discriminating:

```text
observed near-threshold records = 0
observed above-threshold records = 0
observed decohered records = 0
```

## Minimal Bohr-level test

The needed experiment is center-of-mass interferometry with masses spanning:

```text
0.1 M_c, 0.3 M_c, 0.5 M_c, 0.9 M_c, 1.01 M_c, 2 M_c, 5 M_c, 10 M_c
```

with approximately fixed:

- material and geometry;
- spatial separation;
- observation time;
- pressure and temperature;
- optical/electromagnetic noise budget;
- pre-registered visibility threshold.

## Decisive signature

Tamesis v1 expects a one-sided discontinuity:

```text
Gamma_T(M <= M_c) = 0
Gamma_T(M just above M_c) ~= 0.4595 s^-1
```

That is the candidate "Bohr move": not a smooth mass-dependent loss, but a
sharp threshold in center-of-mass coherence.

## Near-term target

Space-based high-mass interferometry around 1e11 amu is the closest mature
mission-class proposal found in the current search. It is still below M_c, but
it would enter the most important pre-threshold region.

The most directly relevant near-threshold proposal found so far is the 2026
nanodiamond/chip route, because its stated mass range crosses M_c. This should
be treated as a critical target for collaboration or reanalysis, not as evidence.

The true critical experiment needs roughly:

```text
3.2e11 amu near M_c
6.4e11 amu at 2 M_c
3.2e12 amu at 10 M_c
```

## Interpretation rule

Do not call a positive or negative result Bohr-level unless it occurs in the
threshold region and beats environmental decoherence, CSL, GRW and DP under the
pre-registered likelihood comparison.
