# Blind calibration of GeV nanodiamond thermometry at 5–20 K

Pacote de colaboração experimental preparado após o congelamento computacional
do Tamesis M_c v1.

## Objetivo único desta fase

Responder experimentalmente:

> Existe uma partícula com centro GeV que funcione como termômetro óptico
> individual, calibrado e pouco perturbativo, entre 5 K e 20 K?

Este pacote não propõe testar Tamesis, colapso quântico, `M_c`, levitação ou
interferometria. O resultado procurado é metrológico e autônomo.

## Limites

- não preencher campos desconhecidos com valores de catálogo;
- não mudar o protocolo v0.6 para acomodar dados observados;
- não enviar todo o arquivo Tamesis na primeira abordagem;
- não chamar simulação de evidência;
- não iniciar A1 antes de Q0 e A0;
- não criar v0.7 sem uma necessidade documentada proveniente do hardware.
