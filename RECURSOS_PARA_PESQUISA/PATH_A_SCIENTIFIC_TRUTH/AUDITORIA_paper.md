# Auditoria — Path A: Precision Physics Results

**Status:** needs_data  
**Classificação:** síntese de previsões cosmológicas/galácticas (S1/E)

## Veredicto

Os valores publicados como “sem parâmetros livres” não vêm acompanhados de um espaço de busca ou pré-registro. A comparação com uma medição tardia de `H_0` não elimina a dependência de calibração e o resultado deve ser confrontado com o conjunto completo de dados cosmológicos.

## Próximo teste

Disponibilizar código, priors e covariâncias; avaliar conjuntamente CMB, BAO, supernovas, SH0ES e curvas de rotação, com análise fora da amostra.
