# Auditoria rigorosa — Fundamental Directionality

Data: 2026-07-30  
Status: argumento de irreversibilidade não estabelecido.

## Achados

Modelar estados como DAG já impõe a ausência de ciclos; isso é uma definição, não uma prova física. A desigualdade de processamento de dados vale sob um canal fixo e não impede recorrência de macroestados quando a descrição microscópica é reversível.

## Teste mínimo

Definir mapa de coarse-graining, medir informação/entropia ao longo de trajetórias e comparar com um sistema Hamiltoniano finito que satisfaz recorrência de Poincaré. A alegação cosmológica precisa de um modelo dinâmico, não apenas de um grafo.
