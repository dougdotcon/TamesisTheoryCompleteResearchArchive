# Auditoria rigorosa — TDTR Simulation Program

Data: 2026-07-30  
Status: metodologia computacional; validação ainda não demonstrada.

## Achados

Descrever um motor de simulação não informa se ele reproduz dados reais, quais parâmetros são ajustados ou como se compara a modelos de matéria escura. A ausência de dark matter no código não é uma previsão; é uma escolha de modelo.

## Teste mínimo

Publicar repositório executável, versão de dados, testes unitários, seeds, análise de convergência e métricas cegas. Comparar a mesma amostra com MOND/TDTR, ΛCDM e modelos bariônicos, usando validação fora da amostra.

## Fontes

- SPARC database, [Lelli, McGaugh & Schombert](http://astroweb.cwru.edu/SPARC/).
- Planck Collaboration, *Planck 2018 results. VI. Cosmological parameters*, DOI [10.1051/0004-6361/201833910](https://doi.org/10.1051/0004-6361/201833910).
