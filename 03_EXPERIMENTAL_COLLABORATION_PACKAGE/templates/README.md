# Templates operacionais

- `LAB_PIPELINE.csv` — prospecção e contatos;
- `Q0_INSTRUMENT_INVENTORY.csv` — hardware;
- `SAMPLE_REGISTRY.csv` — identidade persistente;
- `A0_RUN_LOG.csv` — sessões e decisões;
- `DATASET_RECEIPT.md` — recibo de dataset;
- `TECHNICAL_REJECTION_RECORD.md` — rejeição fundamentada;
- `COLLABORATION_SCOPE.md` — escopo mínimo.

Use `unknown` quando o campo for desconhecido. Célula vazia significa que ainda
não foi preenchida.
