## Evidências

`git ls-remote` confirmou que `v4.32.2` é tag oficial no SHA
`905b958...`; `v4.32.1` é tag oficial no SHA `520045a...`. O checkout atual,
seu `lean-toolchain` e o projeto declaram exatamente `leanprover/lean4:v4.32.2`.

O cache atual foi executado uma única vez. O log bruto foi copiado para
`08_REVIEWS/reproducibility/LAB-0.8-cache-current-revision.log`; o erro foi uma
exceção Windows de arquivo/recurso ausente, sem URL ou HTTP status. A ferramenta
usa `curl` para download e `leantar.exe` do sysroot para extração; ambos foram
localizados, assim a causa primária permanece `CACHE_TOOL_INTERNAL_ERROR`.

O smoke mínimo atual passou, mas os smokes de tática e umbrella falharam por
`.olean` ausente. O probe isolado `v4.32.1` teve cache e build igualmente
falhos, sem downloads ou extrações; não houve migração canônica.
