# Cycle Survival Under Poisson Perturbation of Random Permutations

Standalone, reproducible package for a single closed-form result about a
random-mapping ensemble: a uniform permutation of `[n]`, each point
independently rerouted with probability `c/n` to a uniform destination.
As `n → ∞`, the expected fraction of points left on a cycle converges
(see "Status" below for the exact strength of that convergence claim) to

```
φ_∞(c) = ∫₀¹ e^{-c t²} dt = (1/2)·√(π/c)·erf(√c)
```

Author: Douglas H. M. Fulber.

## Contents

- `paper/cycle-survival.tex` (+ `.bib`) — the paper source; `paper/cycle-survival.pdf` is the compiled result (see `paper/COMPILE.md` to rebuild)
- `proofs/derivation.md` — self-contained derivation with every step and

- `data/` — JSON outputs of the scripts above, generated by the commands below
- `tests/test_formula.py` — pytest suite (49 checks, runs in ~1-2s)

## Status (read this before citing anything as "proved")

This package separates three tiers, matching the archive's theorem
document:

1. **PROVED**, self-contained: the closed form on the limit object
   `L(c)` (Theorem 1), its series and tail asymptotic (Corollaries 4.1,
   4.2), the conditional-`K` mean for every `K` (Wallis integral), the
   `K=1` conditional density, and — on the finite-`n` side — the exact
   `K=0` through `K=5` bridge cases (exact rates `1/(3n²)` at `K=1` and
   `Θ(1/n)` at `K=2,3` — *not* the `Θ(1/n²)` the `K=0,1` pattern alone
   would suggest) plus an unconditional, fully `K`-general reduction
   lemma. `K=1,2` are proved by hand case-analysis; `K=3,4,5` are proved
   by a completely different, later technique — a `K`-uniform
   transfer-matrix/Markov-chain method that reduces the whole
   computation to a mechanical telescoping-sum algorithm — verified
   independently by a hostile adversarial referee across several layers
   (own re-derivation by a different solving technique, own brute force
   including a fresh `n=9` data point, own scripts re-run from scratch)
   with zero errors found.
2. **CONDITIONAL**: the full statement "`φ(n,c) → φ_∞(c)` for every `c`"
   follows from that reduction lemma *only if* an explicitly stated open
   lemma holds for every `K ≥ 6` (the finite-`n` bridge at fixed `K≥6`;
   narrowed from `K≥3` once `K=3,4,5` were proved — see below). That
   lemma is neither proved nor disproved here. The obstruction is now
   precisely named — not "more hand casework," as it was through `K=2`,
   but that the transfer-matrix recursion has so far only been solved
   level-by-level in its "level" variable `r` (`r=0,…,5`), not
   symbolically for general `r`; an induction on `r`, or a
   generating-function-in-`K` argument, are named as concrete (if
   unexecuted) candidate routes. Naming a route does **not** make `K≥6`
   essentially solved — it remains a genuinely open problem. A related
   numerically-verified-but-unproved conjecture about the general-`K`
   rate (`lim n(ψ_n^{(K)}−φ_K) = Kφ_K/4`, confirmed exactly for `K=1..5`,
   CONJECTURED beyond) is stated in `proofs/derivation.md` §6 and is
   never treated as established.
3. **CONJECTURED**, numerically supported (Kolmogorov–Smirnov, no
   rejection) but not proved: the full conditional-`K` cyclic-mass
   *density* for `K≥2` (this is a distributional claim, unrelated to and
   unaffected by the `K=2..5` bridge/mean results in tier 1 above), and
   the resulting unconditional distributional law
   `M(c) =^d min(1, √(E/c))`.

No claim in this package is upgraded past its status in `proofs/derivation.md`.
Full source of record (with the complete, longer proofs and the master
list of every open gap): the archive's internal theorem document,
`05_DISCOVERY_LAB/02_TESTS/CORE_NUMERICS/u12_universality/theorem/THEOREM.md`,
plus its Stage 3 extension resolving `K=2`
(`.../theorem/k2_open_lemma/ATTEMPT.md` and
`adversarial/REFEREE_REPORT.md`) and its Stage 4 extension resolving
`K=3,4,5`
(`.../theorem/k2_open_lemma/k3_attempt_2/ATTEMPT.md` and
`.../k3_attempt_2/adversarial/REFEREE_REPORT.md`) — none included in this
package; this package is meant to stand on its own via
`proofs/derivation.md`.

## Literature priority

A dedicated literature search (22 queries, WebSearch + WebFetch, logged
in full in the archive's `priority_search/SEARCH_LOG.md`) traced the
closest published family — Jaworski 1984 → Jaworski 1998 →
Hansen–Jaworski 2002 → 2006 → 2008 → 2014 — and reached a verdict per
component of this result, honestly separating what is known from what
the search did not find:

| Component | Verdict | Summary |
|---|---|---|
| The model (permutation + independent Bernoulli reroute) | not found | closest family is parametrized by in-degree sequence, not permutation-plus-reroute |
| The limit object (`PD(1)` + Poisson marks) | components known | each piece is classical; this specific combination is not built this way in the literature, because the source literature never starts from a permutation |
| Conditional-`K` law | **already known** | Hansen & Jaworski, EJC 21(1) (2014), #P1.18, Theorem 7(ii), density `2ax(1-x^2)^{a-1}` for their fixed-defect model, `a↔K` — identical functional form, different microscopic model |
| Poisson-mixture closed form (erf) | not found | strongest candidate component of this result for being previously unpublished; the mixture is a question that only arises naturally from the permutation-plus-reroute side, so its absence from the in-degree-sequence literature is expected, not just unsearched |
| Tail exponent `1/2` | exponent known, coefficient/exact-form specific | `1/2` is the universal exponent for cyclic-point density across the whole random-mapping literature; the exact coefficient `√π/2` and purely-exponential correction structure were not found |

**What this does and does not license.** The search is broad (22
queries plus 5 from an earlier pass) but not exhaustive: one classical
source (Kolchin, *Random Mappings*, 1986) remains unverified for lack of
full-text access, reported here as inaccessible, not as ruled out. The
correct phrasing is "not found in the searches performed," never "does
not exist" or "first". No sentence in this package or the paper asserts
priority beyond that, and neither uses an unqualified priority claim for
any result without this caveat attached.

Full search log and per-component reasoning: the archive's
`priority_search/PRIORITY_SEARCH.md` and `priority_search/SEARCH_LOG.md`
(not included in this package).

## Reproducing every figure and number

Requires Python 3.10+, `numpy`, `scipy` (`pytest` additionally for the
test suite). No other dependencies. Every script is deterministic
(fixed seeds where randomness is used) and writes its own JSON output to
`data/`.

```bash
cd tamesis-cycle-survival

# Exact (no-sampling) brute-force enumeration at small n: reproduces
# Proposition 4 (K=1 closed form, exact for n=1..9), plus a raw
# exact-enumeration table for K=2 (n=2..7) -- this script itself only
# prints the raw values, not a comparison to a closed form; the exact
# K=2 closed form phi_n^(2) = 8/15 + 1/(30n) + 7/(10n^2) + 1/(5n^3) is
# now proved (see proofs/derivation.md section 6) but was verified
# independently of this script -- and the full phi(n,c) exact Binomial
# mixture (n=2..4).
python3 simulations/finite_n.py
# -> prints three tables; writes data/finite_n_results.json
# (slower optional ranges: --max-n-k2 8 takes ~30-60s, --max-n-full 5
#  takes a few seconds; n beyond that is impractical, see script docstring)

# Monte Carlo at large n (default n=20000, 400 trials/cell, seed 20260822):
python3 simulations/monte_carlo.py
# -> prints a table of MC mean vs. phi_inf(c) with z-scores; writes
#    data/monte_carlo_results.json

# Series / closed-form / tail-asymptotic cross-checks, all against
# independent quadrature, no data fitting anywhere:
python3 simulations/asymptotics.py
# -> writes data/asymptotics_results.json

# Full pytest suite (49 checks: series vs. integral vs. erf, phi_K vs.
# quadrature, exact finite-n vs. closed form, small MC vs. formula):
python3 -m pytest tests/test_formula.py -v
```

Every number quoted in `paper/cycle-survival.tex` and in
`proofs/derivation.md` is reproduced by one of the commands above; none
is copied from the archive without being independently regenerated by
this package's own clean-room implementation.
