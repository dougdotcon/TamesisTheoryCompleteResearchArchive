# Auditoria — Document A: Complexity Censorship

**Status:** conjectural  
**Classificação:** proposta de classe física e princípio de barreira (S1/Q)

## Veredicto

“Fisicamente realizável” não é uma classe formal até que hardware, ruído, precisão, paralelismo e custo de controle sejam definidos. Um argumento de dissipação para uma arquitetura não implica um lower bound para todas as arquiteturas nem P ≠ NP.

## Próximo teste

Definir `P_phys` e mostrar uma redução que transfira o lower bound para o modelo clássico; caso contrário, declarar apenas uma previsão sobre uma plataforma específica.
