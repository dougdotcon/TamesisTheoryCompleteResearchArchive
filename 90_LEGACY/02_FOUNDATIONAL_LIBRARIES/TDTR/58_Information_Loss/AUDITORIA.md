# Auditoria rigorosa — Information Loss as Constructive Principle

Data: 2026-07-30  
Status: hipótese de coarse-graining; não resolução do paradoxo.

## Achados

Uma aplicação parcial que elimina graus microscópicos pode gerar leis efetivas, mas isso não demonstra perda fundamental de informação. Para sistemas quânticos, é necessário dizer se $\Theta$ é CPTP, isométrica em um ambiente maior ou não linear; cada escolha tem consequências distintas para entropia, causalidade e unitariedade.

## Teste mínimo

Construir um canal explícito, calcular entropia de von Neumann e informação recuperável, e comparar com uma dilatação unitária de Stinespring. Separar o caso de coarse-graining efetivo do problema de informação de buracos negros.
