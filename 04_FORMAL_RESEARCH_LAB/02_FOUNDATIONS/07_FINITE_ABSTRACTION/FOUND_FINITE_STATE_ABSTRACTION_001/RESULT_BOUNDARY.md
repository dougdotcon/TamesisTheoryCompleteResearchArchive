# Fronteira do resultado

## A fronteira epistemológica, literal

```text
Uma semiconjugação garante que a trajetória concreta é observada
corretamente pela trajetória abstrata.

Uma igualdade entre estados abstratos significa somente que os
estados concretos possuem a mesma observação.

Ela não implica, por si só, igualdade entre os estados concretos.

Um CycleWitness correto no sistema abstrato produz
automaticamente recorrência observacional no sistema concreto.

A reflexão dessa recorrência como igualdade concreta exige uma
hipótese adicional de separação ou injetividade sobre a órbita
alcançada.
```

## Proibido afirmar

```text
todo ciclo abstrato e concreto;
semiconjugacao implica bissimulacao;
abstracao muitos-para-um reflete igualdade;
ciclo abstrato nunca e espurio;
qualquer abstracao externa foi modelada corretamente.
```
