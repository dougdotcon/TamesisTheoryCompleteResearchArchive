This repository preserves the complete Tamesis research trajectory and its
current testable branch, **Tamesis M_c v1**. The computational program has
reached its legitimate stopping point. It has produced a fixed phenomenological
hypothesis, model comparisons, synthetic stress tests, metrology requirements,
and a fail-closed A0/A1 hardware protocol. It has **not** produced experimental
evidence for Tamesis.

The next scientifically meaningful contribution must contain real hardware
metadata, calibration records, GeV-particle spectra, thermal time series, or A0
campaign records. No v0.7 is planned without such input.
